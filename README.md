# Old Back

[Abrir la aplicación](https://jaimearandacongil.github.io/oldback/)

Edición pública compilada · versión 4.18.0. Las fuentes se conservan por separado.

[Probar la nueva experiencia](https://jaimearandacongil.github.io/oldback/?v=4.18.0&experience=next#inicio): carta, comparación en tienda, colección y viaje. El enlace habitual conserva la interfaz anterior durante el rediseño por fases.

Preparar sin red permite elegir todas las fotos, solo miniaturas o fotos completas de sets/portfolios. El reconocimiento conserva todo el catálogo; OCR y mejora neuronal son opcionales. Cada capacidad tiene comprobación propia. Los archivos verificados se reutilizan entre versiones.

Tu colección se guarda en el navegador del dispositivo. Actualizar en esta misma dirección conserva los portfolios. Exporta una copia desde Info → Datos de mi colección antes de cambiar de teléfono o borrar datos del navegador.

Precios TCGplayer y cambio actualizados por el trabajo programado; PriceCharting conserva su fecha de referencia. La publicación preserva prices/references.json, prices/history.json y su trabajo diario.
